## 공개소스 완전자동 가능성 검증 결과

| 소스 | 컬럼 | 자동화 | 상태 |
|---|---|---|---|
| **FRED** | ust10 | ✅ 즉시 | 키 불필요 CSV 엔드포인트, 실측 성공(DGS10 최근치 확인) |
| **ECOS** | base_rate, cd91, (kofr, usdkrw) | ⚠️ 키 1회 | **무료 API 키 필요**(한은 ECOS 등록). 키 넣으면 완전 자동. 현재 `ECOS_API_KEY` 미설정 |
| **KOFR** | kofr | ⚠️ | ECOS 경유 or kofr.kr. ECOS로 묶는 게 단순 |
| **FX** | usdkrw | ⚠️ | ECOS 경유(키) or smbs.biz 스크레이핑 |
| **KRX** | 선물 OHLC/settle/vol/oi, 투자자수급, 국고금리, 베이시스, 만기 (약 29컬럼) | ⚠️ 구축필요 | **pykrx 1.2.8 커버 실패** — `get_future_ohlcv` NotImplemented, 국고채수익률 엔드포인트 깨짐, 파생 투자자수급 함수 없음. → **KRX MDC JSON 직접 호출**로 가야 함(키 불필요, OTP/세션 핸드셰이크 필요). 사양서가 예고한 #1 리스크 확인됨 |

- **완전 자동 가능**: 그렇다. 단 두 가지 전제 — ① **ECOS 무료 키 발급 1회**, ② **KRX는 MDC 직접 호출 레이어 구축**(pykrx로는 안 됨).
- **당장 키 없이 되는 것**: FRED(ust10).
- **인포맥스 4개**(irs3y/irs10y/ois3y/kr_cds5): 예정대로 맨 마지막. 지금은 빈칸.
