# 데이터 사전 (ktb_daily 47컬럼)

> 각 데이터가 **무엇이고, 실제로 어디서 어떻게 뽑았는지**. 차장님 원본 체크리스트 대비 현황 포함.
> 저장소: Supabase Postgres `public.ktb_daily` (동시에 로컬 `out/ktb_daily.csv`).
> 이력: **1999~현재, 거래일만**(휴장일 행 없음). 결측=빈칸(NULL), 0=진짜 0.

---

## 0. 계획 대비 실제 — 핵심 변경

차장님 원본은 선물 데이터를 전부 **KRX**로 계획했으나, 실제 구현에선 소스가 바뀌었다(더 깊고 연속적):

| 데이터군 | 차장님 계획 | **실제 사용** | 이유 |
|---|---|---|---|
| 선물 시세·수급·베이시스 | KRX | **인포맥스 국채연결선물 C65/C67** | KRX OpenAPI는 2011+·베이시스 없음. 연결선물은 2000/2008+ 연속 |
| 국고채금리·기준금리·CD·환율 | KRX/KOFIA/ECOS | **ECOS(한국은행)** | 상수만기 연속, 2000+ |
| IRS·OIS·**KOFR** | KOFIA/Bloomberg | **인포맥스 애드인** | 사내단말 IMDH. KOFR은 ECOS보다 신선(T+1) |
| 미국채10년 | FRED | **FRED** | 계획대로 |
| 만기·roll·누적 | KRX 수집 | **파이프라인 계산** | 날짜/누적합으로 산출 |

## 1. 국채선물 — 인포맥스 국채연결선물 (16컬럼)

**출처**: 인포맥스 [1333] Excel · `선물 › 지수/금리 › 국채연결선물`
**종목코드**: `C65`(3년), `C67`(10년) — IMDH 히스토리 함수, 2000/2008년~현재 연속
**왜 "연결"**: 선물은 분기(3·6·9·12월)마다 월물이 바뀌는데, 연결선물이 최근월물을 자동 이어붙여 하나의 연속 시계열로 제공. 롤 시점은 `roll_flag`로 표시.

| 컬럼 | 인포맥스 항목 | 설명 |
|---|---|---|
| `ktb3_settle` / `ktb10_settle` | 현재가 | 일 종가(정산가 대용 — 옛 정산가 결측 많아 현재가 사용) |
| `ktb3_chg` / `ktb10_chg` | 전일대비 | 전일 종가 대비 변화폭 |
| `ktb3_open/high/low` / `ktb10_open/high/low` | 시가/고가/저가 | 일봉 OHLC |
| `ktb3_vol` / `ktb10_vol` | 거래량 | 그날 체결된 **계약 수** (변동성 아님) |
| `ktb3_oi` / `ktb10_oi` | 미결제약정수량 | 청산 안 된 잔여 계약 수 |
| `ktb3_theo_basis` / `ktb10_theo_basis` | 이론베이시스 | 이론가 − 실제 선물가 (틱). 정확히 0 = 미계산 → 빈칸 |
| `fx_net_ktb3` / `fx_net_ktb10` | 외국인합 매수수량 − 매도수량 | 외국인 순매수 계약수 (+매수/−매도) |
| `bank_net_ktb3` / `bank_net_ktb10` | 은행 매수−매도 | 은행 순매수 |
| `itrust_net_ktb3` / `itrust_net_ktb10` | 투신 매수−매도 | 투신(자산운용) 순매수 |
| `ins_net_ktb3` / `ins_net_ktb10` | 보험 매수−매도 | 보험 순매수 |

> **순매수 = 매수수량 − 매도수량**으로 계산(인포맥스 '순매수수량' 열은 투신 등 결측 있음).

**이력 시작**: 3년 시세 2007-08 / 10년 2008-02(상장) / 3년 수급 2001 / 10년 수급 2010-10.

## 3. 스왑·KOFR — 인포맥스 애드인 IMDH (4컬럼)

**출처**: 인포맥스 [1333] Excel · SWAP(`금리/수익률 › SWAP`) + KOFR(`ECO 785831`)

| 컬럼 | 인포맥스 종목 | 설명 | 이력 |
|---|---|---|---|
| `irs3y` / `irs10y` | `IRSTP1KRW03Y` / `IRSTP1KRW10Y` | 원화 이자율스왑(MID종가, %) | 2005-07+ |
| `ois3y` | `IRSKM5KRW03Y` (KOFR OIS) | 원화 익일물지수스왑(%) | 2022-02+ (KOFR 기반) |
| `kofr` | `785831` (ECO) | 무위험지표금리 KOFR(%). **T+1 픽싱**(익영업일 오전 공시). ECOS보다 신선 | **2018-01-02+** |

> ⚠️ **KOFR 2021-11-26 이전은 예탁결제원 '역산(백데이팅)' 시계열.** KOFR은 「금융거래지표법」에 따라 2021-11-26부터 정식 공시됐고, 이전 구간은 KOFR Index 기준시점(**2018-01-02 = 1,000**)부터 **동일 방법론(실제 익일물 RP 거래 거래량가중)으로 소급 산출**한 값이다(정식공시 이전 = "단순 정보제공"). **가짜 대용치가 아니라 공식 역산치 → 유지.** 정식 벤치마크 구간(2021-11-26+)과 구분이 필요하면 이 경계를 기준으로.

## 5. 파생 계산 — 파이프라인이 산출 (4컬럼 + date)

| 컬럼 | 계산법 |
|---|---|
| `date` | 거래일 (KTB 선물이 거래된 날) |
| `days_to_expiry` | 분기(3·6·9·12월) **셋째 화요일**(최종거래일)까지 잔존일 |
| `roll_flag` | `days_to_expiry`가 전일 대비 상승 = 1 (최근월물 롤오버), 아니면 0 |

## 5.5 MACRO 축 (v2.5 신규 — 인포맥스 ECO, 발표일 배치)

월별 지표라 **참조월이 아니라 실제 발표일**에 값을 넣는다(룩어헤드 방지). 값은 발표일 이후 다음 발표 전까지 **직전값 유지(ffill)**. 차장님 v2.5 실측 역산 — cpi·core·bei·exports는 **바이트 일치**, ip는 개정차만.

| 컬럼 | 인포 코드 | 의미 | 계산·배치 |
|---|---|---|---|
| `cpi_yoy` | ECO 701979(총지수) | 소비자물가 전년동월비 | 지수→yoy, **익월 5일** |
| `core_cpi_yoy` | ECO 701996(근원지수) | 근원 CPI 전년동월비 | 지수→yoy, **익월 5일** |
| `bei` | ECO 703923 | 기대인플레율(향후1년 서베이) — ※시장 BEI 아님 | 현재가, **익월 1일** |
| `exports_yoy` | ECO 557150(수출액) | 수출금액 전년동월비 | 금액→yoy, **익월 16일** |
| `ip_yoy` | ECO 704507 | 전산업생산 전년동월비 | 현재가, **익익월 1일**(개정 잦음) |

> 발표일 규칙은 config.MACRO_SPEC(place: d5/m1/m2/d16 = 각 지표 발표 시점). "이후 첫 거래일"부터 ffill.

## 7. 데이터 규율

- **결측 = 빈칸(NULL)**, 0은 진짜 0. 다운스트림에서 **빈칸을 0으로 채우지 말 것**.
- **가격필드(settle/OHLC/basis) 0 = 미기록 → 빈칸**. vol/oi/net의 0 = 진짜(거래없음/순매수0).
- **완결성 점검**: 매 실행 시 XKRX(한국거래소 캘린더) 거래일 대비 핵심소스 누락을 리포트에 경보.
- **급변은 살림**: 범위 초과 변동(위기·금리인하·롤갭)은 드롭 아니라 플래그(적재+경고).
