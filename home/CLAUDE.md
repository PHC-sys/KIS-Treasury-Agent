# CLAUDE.md — KTB 데이터 수집 시스템

이 레포는 국채선물(3년·10년) 트레이딩 에이전트다. Phase 0(데이터 레이어) 완료 → Phase 2(에이전트) 진행 중.

> **▶ 이어받는 세션은 [docs/개발_인수인계.md](docs/개발_인수인계.md)를 먼저 읽어라.**
> 프로젝트 전모·인포맥스 IMDH 수식/코드·최근 결정·다음 할 일이 거기 다 있다.

컬럼 의미는 [docs/데이터_사전.md](docs/데이터_사전.md), 원설계는 [docs/데이터수집_사양.md](docs/데이터수집_사양.md). 아래는 절대 규칙.

## 최우선 원칙
- **멱등성**: update.py를 몇 번 돌려도 결과 동일. 저장 키 = (date, field), 충돌 시 upsert.
- **증분 수집**: 매 실행은 마지막 수집일 다음날~오늘만. 최초 1회만 2년 백필.
- 완벽보다 "돌아가고 매일 갱신되는 것"이 우선.

## 데이터 규율 (조용한 오염 = 최대 적)
- 모든 값에 as_of(데이터 기준일) + fetched_at(인출 시각) + source 기록.
- 적재 전 sanity check: 영업일 일치 / 전일과 완전동일값 아님(동결 감지) / 변화폭 물리적 범위 / vol·oi≥0.
  실패 시 그 (date,field)만 격리하고 로그에 남긴다. **조용히 넘어가지 않는다.**
- raw 원본 응답을 raw/ 에 그대로 보관(수정 금지).
- 실패는 시끄럽게. 빈 값/옛 값을 성공인 척 반환하는 경로 금지.

## 출력 규칙 (차장님 스키마 — 변경 금지)
- ktb_daily **63컬럼**, 순서 고정. 기존 순서는 절대 불변, 신규는 **뒤에만 추가**.
  (42=원설계 → 47 MACRO → 48 wti → 56 수급 세분화 → 63 미국채 OHLC. 이력은 인수인계 §7)
- 수급 항등식 `fx+bank+itrust+ins+sec+indiv+etc = 0`이 매 실행 자동검증된다(config.FLOW_IDENTITY).
  ★`pension_net`은 `etc_net`의 **부분집합** — 합산·항등식에 같이 넣으면 이중계산된다.
- 결측 = 빈칸(0 절대 금지). 휴장일 행 없음(거래일만).
- fx_cum_ktb3/10은 수집 아님 — fx_net 누적합으로 파이프라인이 계산.
- note는 수집기가 비움.

## 소스 경계 (실측 확정 — 상세는 인수인계 §5)
- **infomax**(Excel 애드인 IMDH, 매일 로그인+run.bat): 선물 시세·OHLC·거래량·OI·베이시스·수급(3·10년), irs3y/irs10y/ois3y, **kofr**.
- **ecos**(무료 키): base_rate, cd91, y_ktb3/10/30. **fred**: ust10(한·미 시차 정합). **fx**: usdkrw.
- **manual**: kr_cds5(S&P 라이선스 → manual_input.csv). KRX는 인포맥스 연결선물로 대체돼 미사용.

## 작업 방식
- 엔드포인트/스펙이 불확실하면 추측해서 코드부터 쓰지 말고 뭘 모르는지 먼저 말한다.
- KRX는 pykrx 먼저 시도, 파생 수급 커버 안 되면 KRX MDC JSON 엔드포인트로. 인증키는 사용자가 넣는다.
- 자격증명(API 키·비밀번호)은 코드에 하드코딩하지 않는다. 사용자가 환경변수/파일로 주입.
- 나(Claude Code)는 로컬 실행 결과를 사용자에게 보여주고 함께 디버깅한다.
